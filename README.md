# 🛒 Supermarket Sales Project Series

This portfolio project showcases a multi-phase, tool-diverse approach to analyzing supermarket sales data. Using Excel, SQL, and (soon) Power BI, I explored product popularity, customer purchasing behavior, sales trends, and customer loyalty metrics. The purpose of this series is to demonstrate both technical depth and strategic insight across tools used by modern analysts.
